# Einstieg in Ansible - Das offizielle Repository zum Buch
Dieses Repository begleitet das Buch "[Einstieg in Ansible: Schritt für Schritt vom ersten Playbook zur professionellen Automatisierung](https://www.mitp.de/IT-WEB/Einstieg-in-Ansible.html)" von Denis Racz (mitp-Verlag).

Es dient als praktischer Werkzeugkasten für alle Beispiele aus dem Buch.

---
## Einleitung
Dieses Repository ist **kein fertiges Produkt**, sondern bewusst als **Lern- und Arbeitsumgebung** aufgebaut.

Alle enthaltenen Playbooks, Roles und Inventories sind parallel zum Buch entstanden:
- Schritt für Schritt aufgebaut  
- kontinuierlich erweitert  
- teilweise vereinfacht, um Konzepte verständlich zu machen  

Das bedeutet:
⚠️ **Nicht jedes Beispiel ist isoliert sofort lauffähig.**  
Einige Inhalte setzen vorherige Schritte aus dem Buch voraus oder müssen an Ihre Umgebung angepasst werden.

Dieses Repository soll Ihnen helfen, **Ansible wirklich zu verstehen**, nicht nur auszuführen.
